## Доступ та повноваження

<Question q="Як увійти до KSeF?">
  До Aplikacji Podatnika KSeF (ap.ksef.mf.gov.pl) ти входиш через login.gov.pl (Довірений профіль,
  mObywatel, онлайн-банкінг, е-посвідчення) або кваліфікованим підписом чи печаткою. Довірений
  профіль (Profil Zaufany) найзручніший для більшості підприємців: його можна отримати безкоштовно
  через онлайн-банкінг або в органах влади. Сертифікат KSeF і токен призначені для програм, які
  підключаються до KSeF через API. Увійти ними до Aplikacji Podatnika не вийде (Podręcznik KSeF 2.0,
  cz. I).
</Question>

<Question q="Що таке ZAW-FA?">
  ZAW-FA — це форма повідомлення про надання або скасування повноважень у KSeF, яку подають до
  податкової інспекції на папері, через e-Urząd Skarbowy або e-Doręczenia. Вона потрібна лише тоді,
  коли платник не є фізичною особою і не має кваліфікованої печатки, або коли його підпис чи печатка
  не містять NIP або PESEL. В інших випадках повноваження надаються електронно.
</Question>

<Question q="Як уповноважити бухгалтера для KSeF?">
  Повноваження ти надаєш електронно в Aplikacji Podatnika KSeF 2.0 (панель повноважень) або через
  API. Форма ZAW-FA в податковій інспекції потрібна лише у виняткових випадках, наприклад коли ти не
  фізична особа і не маєш кваліфікованої печатки. Уповноваження визначає, чи може бухгалтер лише
  переглядати рахунки, чи також їх виставляти. Бухгалтерська фірма зазвичай сама просить клієнтів
  про відповідне уповноваження, тож запитай свого бухгалтера.
</Question>

<Question q="Що таке сертифікат KSeF?">
  Сертифікат KSeF — це електронне посвідчення особи, що використовується для автентифікації в API
  KSeF. Завантажується з системи МФ і дозволяє програмам та інтеграторам входити до KSeF без
  Довіреного профілю. Типи сертифікатів визначаються за функцією: тип 1 слугує для автентифікації в
  KSeF, тип 2 для виставлення рахунків в офлайн-режимі. Один сертифікат має один тип.
</Question>

<Question q="У чому різниця між сертифікатом типу 1 і типу 2?">
  Вони відрізняються функцією, а не тим, хто ними володіє. Сертифікат типу 1 (в API: Authentication)
  слугує для автентифікації в KSeF. Сертифікат типу 2 (в API: Offline) слугує для виставлення
  рахунків в офлайн-режимі. Один сертифікат має один тип, тому для обох цілей потрібні два
  сертифікати.
</Question>

<Question q="Що таке токен автентифікації?">
  Токен автентифікації — це рядок символів, який ти генеруєш в Aplikacji Podatnika KSeF і
  використовуєш замість сертифіката для автентифікації в API. Токени зручніші для інтеграторів і
  менших систем, бо не потребують управління PKI-сертифікатами. Токен має обсяг повноважень, наданий
  під час генерування, і, згідно з Podręcznik KSeF 2.0 (cz. I), діє, доки ти його не відкличеш в
  Aplikacji Podatnika. Розпорядження передбачає токени до 31 грудня 2026 року, але МФ вирішило їх
  зберегти. Детальніше в статті про [токени KSeF після 2026 р.](/blog/tokeny-ksef-po-2026)
  (польською).
</Question>
