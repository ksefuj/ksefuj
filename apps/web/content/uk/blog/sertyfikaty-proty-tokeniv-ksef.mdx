Якщо ти виставляєш рахунки вручну в Aplikacja Podatnika (веб-застосунку KSeF для платника), входь через Profil Zaufany (безкоштовний польський довірений профіль): його достатньо для JDG (jednoosobowa działalność gospodarcza, польський ФОП). Якщо рахунки надсилає програма (Fakturownia, inFakt, wFirma, власний ERP), вона підключається через API і потребує **токена** або **сертифіката KSeF**. Profil Zaufany там не працює.

## Способи входу коротко

| Спосіб                                                  | Режим   | Для кого                                           | Вартість          |
| ------------------------------------------------------- | ------- | -------------------------------------------------- | ----------------- |
| Profil Zaufany, mObywatel, банк                         | браузер | будь-який підприємець                              | безкоштовно       |
| е-посвідчення (e-dowód, через login.gov.pl)             | браузер | будь-хто з активованим новим посвідченням          | безкоштовно       |
| Кваліфікований підпис / печатка                         | браузер | особи та організації з кваліфікованим сертифікатом | платно (підписка) |
| Сертифікат KSeF (тип 1: автентифікація, тип 2: offline) | API     | ERP-системи, інтегратори                           | безкоштовно       |
| Токен автентифікації                                    | API     | програми для рахунків, інтегратори                 | безкоштовно       |

## Profil Zaufany і е-посвідчення: ручний вхід

Якщо ти подавав PIT онлайн або входив до ZUS (польський соцстрах), Profil Zaufany у тебе, імовірно, вже є. Якщо ні, його можна оформити за кілька хвилин через інтернет-банкінг, застосунок mObywatel, ePUAP (pz.gov.pl) або в податковій.

Він дає повний доступ до [Aplikacja Podatnika](https://ap.ksef.mf.gov.pl/): виставлення рахунків через форму, перегляд рахунків від контрагентів і надання доступів іншим людям, наприклад бухгалтерській конторі.

Е-посвідчення працює так само, якщо воно активоване для електронного підпису (одноразовий візит до установи). Частіше обирають Profil Zaufany, бо він не потребує зчитувача карток. В Aplikacja Podatnika можна також увійти через mObywatel чи інтернет-банкінг, а з е-посвідченням через login.gov.pl.

## Кваліфікований підпис і печатка: якщо вони вже є

Кваліфікований електронний підпис (стандарт eIDAS) видають комерційні провайдери, зокрема Certum, Sigillum і EuroCert, за річною або багаторічною підпискою. У KSeF він дає той самий доступ через браузер, що й Profil Zaufany, тож має сенс переважно тоді, коли ти вже користуєшся ним для e-KRS, тендерів чи договорів.

Кваліфікована печатка є аналогом підпису для юридичної особи і також є способом входу в KSeF.

## Токен: найпростіший доступ для програми

Токен це рядок символів, який ти генеруєш в Aplikacja Podatnika і вводиш у налаштуваннях програми. Інфраструктури сертифікатів він не потребує. Діє до відкликання, має обсяг прав (наприклад, лише виставлення або лише читання), а скасувати його можна одним кліком, якщо ти змінюєш постачальника програми.

За чинним розпорядженням токени можна використовувати до 31 грудня 2026 року. Міністерство фінансів оголосило, що токени залишаться довше, і має намір змінити розпорядження. Станом на 7 жовтня 2026 року зміни ще немає.

## Сертифікат KSeF: тип 1 (автентифікація) і тип 2 (offline)

Сертифікат це довговічніше підтвердження особи для доступу через API, яке завантажують із системи МФ. Для складних впроваджень, що обслуговують багатьох платників, він підходить краще за токен. Типи розрізняються за функцією, а один сертифікат має лише один тип:

- **Тип 1** (в API `Authentication`) призначений для автентифікації в KSeF.
- **Тип 2** (в API `Offline`) призначений для виставлення рахунків у режимі offline.

Тож у бухгалтерської контори чи інтегратора власного типу сертифіката немає. Хто і від чийого імені може діяти, випливає з дозволів, наданих у KSeF.

## Дозволи для бухгалтера і коли потрібен ZAW-FA

Дозволи, зокрема для бухгалтерської контори, надають електронно в Aplikacja Podatnika KSeF 2.0 або через API. Це основний шлях. Форма ZAW-FA, яку подають у податковій, потрібна лише тоді, коли платник не є фізичною особою й не має кваліфікованої печатки, або коли в підписі чи печатці немає NIP чи PESEL.

Обсяг прав ти встановлюєш сам: лише читання, лише виставлення або повний доступ. Узгодь його з бухгалтером і не давай більше, ніж потрібно. Контора зазвичай сама попросить дозволи і проведе тебе через процес.

## Що обрати у твоїй ситуації

| Твоя ситуація                                       | Спосіб                                                                                |
| --------------------------------------------------- | ------------------------------------------------------------------------------------- |
| JDG, рахунки вручну в Aplikacja Podatnika           | **Profil Zaufany**                                                                    |
| Програма для рахунків (Fakturownia, inFakt, wFirma) | **Profil Zaufany** для входу + **токен** для програми                                 |
| Компанія з власним ERP                              | **Сертифікат тип 1** або токен                                                        |
| Бухгалтерська контора з багатьма клієнтами          | **Дозволи**, надані клієнтом в Aplikacja Podatnika + **сертифікат тип 1** (або токен) |
| Розробник, що інтегрує KSeF                         | **Токен** для старту, **сертифікат тип 1** у продакшені (тип 2 для режиму offline)    |
| Кваліфікований підпис є з інших причин              | Можеш використати його замість Profil Zaufany                                         |

Якщо виставляєш рахунки зрідка, можеш глянути на e-mikrofirma, безкоштовний застосунок МФ для найменших підприємців. Підтримка KSeF у ньому обмежена і змінюється, тому перед вибором перевір сайт МФ.

Решту підготовки ми описали в матеріалі [KSeF з 1 квітня 2026](/uk/blog/ksef-z-1-kvitnya-2026). Щоб перевірити XML-файл перед відправкою, завантаж його у [валідатор ksefuj.to](/uk): він працює в браузері, а файл не залишає твій комп'ютер.
